# Dharun Kumar M — Portfolio Website

A cinematic, modern, high-performance portfolio website engineered for **Dharun Kumar M**, Aspiring Software Development Engineer specializing in Java, Full-Stack Development, FastAPI, Databases, and AI.

## 🚀 Live Demo
- **GitHub Pages**: https://dharun2712.github.io/Portfolio_new/

## 🛠️ Tech Stack
- **Frontend**: Semantic HTML5, Modern CSS3 (Grid, Flexbox, Custom Properties, Glassmorphism), Vanilla JavaScript ES6+
- **Typography**: DM Mono, Manrope, Plus Jakarta Sans
- **Deployment**: GitHub Pages (Automated with GitHub Actions)

## 💻 Local Development

Clone the repository and run locally:

```bash
# Clone the repository
git clone https://github.com/Dharun2712/Portfolio_new.git

# Navigate to project directory
cd Portfolio_new

# Run with any static server (e.g., npx serve)
npx serve . -l 4173
```

Or open `index.html` directly in your browser.
